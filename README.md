# pEvo

Evolução de bases em Java com ondas de inimigos e visualização em Processing.

## Requisitos

- JDK 17 ou superior
- Maven

## Executar

PowerShell:

```powershell
mvn compile exec:java
```

Bash:

```bash
mvn compile exec:java
```

A janela do Processing abre a população. Precisa de ambiente gráfico.
